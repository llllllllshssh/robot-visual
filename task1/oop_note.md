# 类与对象 学习笔记（TASK1）

## 一、类和对象是什么

- **类（class）**：是一个模板或者说图纸，把一类事物共有的属性（数据）和方法（能做的事）打包在一起。比如“机器人”这个类，规定了每个机器人都有名字、速度，都能移动。
- **对象（object）**：是根据类这个模板造出来的具体个体。比如根据 Robot 类造出来的“主战坦克”“侦察小车”，就是两个具体对象。
- 简单理解：类是图纸，对象是按图纸造出来的实物；先有类，再用类生成对象。

## 二、性质和适用场景

- 类把相关的数据和操作这些数据的函数放在一起，数据和操作不再各写各的，结构更清楚。
- 适合用来描述一类有共同特征、共同行为的事物，比如机器人、车辆、学生信息、商品等。
- 一个类可以造出多个对象，每个对象的属性值可以不一样，但行为方式都按类里定义的来。

## 三、三大特性

### 1. 封装
- **作用**：把内部细节藏起来，对外只留出必要的接口。外面不用关心内部怎么实现，只要调用对外的方法就行，也避免被随便改内部数据。
- **Python 怎么实现**：属性名前面加单下划线（如 `_name`）表示约定上的内部属性，再通过方法去访问和修改。
- **C++ 怎么实现**：用 `private` 把内部成员藏起来，用 `public` 暴露对外的接口。
- **本次代码对应**：Robot 类里的 `_name`、`speed` 就是内部属性，外部通过 `move()`、`get_name()` 来使用。

### 2. 继承
- **作用**：子类直接复用父类已经写好的属性和方法，不用重复写一遍；在父类基础上再扩展自己的东西，减少重复代码。
- **本次代码对应**：`TankRobot`、`ScoutRobot` 都继承自 `Robot`，直接拥有了名字和速度，再各自补充自己的特点。

### 3. 多态
- **作用**：同一个接口（方法名），不同对象调用时执行各自不同的逻辑。调用方不用管具体是哪个子类，统一调用同一个方法名即可。
- **本次代码对应**：两个子类都重写了父类的 `move()`，在循环里统一调用 `rob.move()`，坦克走履带行进、侦察车高速巡逻，表现出不同行为。

## 四、语法格式对照

### Python 基本写法
```python
class Robot:                      # 定义类
    def __init__(self, name):      # 构造方法，初始化对象属性
        self._name = name         # self 代表当前对象自己

    def move(self):               # 定义方法
        pass

class TankRobot(Robot):           # 继承 Robot
    def __init__(self, name, gun):
        super().__init__(name)    # 调用父类构造方法
        self.gun = gun
```
### C++ 基本写法
```cpp
class Robot {                     // 定义类
private:                           // 内部成员，外部不可直接访问
    string name;
protected:
    int speed;
public:
    Robot(string n) { name = n; } // 构造函数
    virtual void move() {}        // 虚函数，供子类重写
    string get_name() { return name; }
};

class TankRobot : public Robot {   // 公有继承 Robot
public:
    TankRobot(string n) : Robot(n) {}
    void move() override {}       // 重写父类虚函数
};
```

## 五、自己的理解

学完之后我觉得，类和对象主要是把“数据”和“操作数据的方法”绑到一起，按事物的类别来组织代码。和以前面向过程、一步一步写函数相比，面向对象更贴近现实里分类思考的方式：同类事物放在同一个类里，各对象之间互不干扰，改一个类不会牵连其他地方。继承让重复的代码可以复用，多态让同一个调用能适配不同的子类，封装则把内部细节保护起来，后期维护和扩展都更方便。
